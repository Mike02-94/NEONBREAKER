Neonbreaker is a vibrant brick-breaking arcade game with a neon-inspired aesthetic.

Featuring smooth controls, progressive difficulty, power-ups, and retro-style effects, Neonbreaker delivers a fast-paced and visually striking twist on the classic Breakout gameplay.
